## Component Design Rules

### Reusable components (`components/`)

| Component | Required props | Variants | Styling strategy |
|-----------|---------------|----------|-----------------|
| `Button` | `children`, `onClick?` | `variant: 'primary' \| 'secondary' \| 'ghost' \| 'danger'`, `size: 'sm' \| 'md' \| 'lg'` | `cva` variant map |
| `Avatar` | `name` | `size: 'sm' \| 'md' \| 'lg'` | Inline Tailwind; initials derived with `initials.ts` |
| `Badge` | `label` | `variant: 'default' \| 'success' \| 'warning' \| 'danger' \| 'info'` | Variant color map |
| `StageChip` | `stage: PipelineStage` | — (stage IS the variant) | `STAGE_COLORS` constant map |
| `KpiCard` | `label`, `value` | `delta?: number` (optional trend) | Tailwind utility classes |
| `Table` | `columns`, `data` | `loading?: boolean` | Tailwind; shimmer skeleton when loading |
| `EmptyState` | `title` | `icon?`, `description?`, `action?` | Centered layout, muted palette |

### No inline variant logic — use constant maps

```tsx
// ✅
const STAGE_COLORS: Record<PipelineStage, string> = {
  'AI Shortlisted': 'bg-celestial-blue text-white',
  // …
};

// ❌
className={stage === 'Selected' ? 'bg-commerce-green' : stage === 'Rejected' ? 'bg-gray-500' : '…'}
```

### TypeScript conventions

- Strict mode enabled (`"strict": true` in `tsconfig.json`).
- Path aliases configured in `vite.config.ts` and `tsconfig.json`:
  - `@/*` → `src/*`
- Barrel files (`index.ts`) for `components/`, `lib/api/`, `lib/constants/` — do not create barrels for pages (hurts code-splitting).
- Prefer `interface` for component props, `type` for unions and API response shapes.

## Naming Quick Reference

| What | Convention |
|------|-----------|
| React component file | `PascalCase.tsx` |
| Hook file | `useXxx.ts` |
| API module | `xxx.api.ts` |
| Type file | `xxx.types.ts` |
| Constant file | `xxx.constants.ts` |
| NestJS service | `xxx.service.ts` |
| NestJS controller | `xxx.controller.ts` |
| DTO | `xxx.dto.ts` |
| Prisma model | `PascalCase` |
| Prisma field | `camelCase` |
